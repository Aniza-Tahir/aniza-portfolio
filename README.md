## Before publishing
1. Replace `YOUR-EMAIL@example.com` with the verified professional email.
2. Replace LinkedIn/Fiverr placeholder links with verified URLs.
3. Add original project screenshots and the verified certificate image.
4. Add the actual writing samples when their source text/links are available.
5. Test the contact form after connecting it to a real form/email service if desired.

The site deliberately avoids unsupported client results, testimonials, statistics, credentials, years of experience, or performance claims.
